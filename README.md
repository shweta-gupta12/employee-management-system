# Employee Management System

A full-stack Employee Management System built using React JS, Spring Boot, and MySQL.

## Features
- Add Employee
- View Employee
- Update Employee
- Delete Employee

## Technologies Used
### Frontend
- React JS
- Bootstrap
- Axios

### Backend
- Spring Boot
- Spring Data JPA
- Hibernate

### Database
- MySQL

## Project Structure
- react-frontend-project
- springboot_backend_project
